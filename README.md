# CBSE Study Apps

Interactive study apps for CBSE students, built with Python + Streamlit.
Free to use, works offline, no login needed.

## Projects

| Folder | Subject | Class | Status |
|--------|---------|-------|--------|
| [Class-XI-IP](./Class-XI-IP) | Informatics Practices (Code 065) | XI | ✅ Complete |

More subjects coming — Class XI CS, Class XII IP, Class XII CS.

## How to Run Any App

1. Download or clone this repository
2. Open the subject folder (e.g. `Class-XI-IP/`)
3. **Windows:** double-click `run.bat`
   **Mac/Linux:** run `./run.sh` in terminal

The launcher installs dependencies automatically and opens the app in your browser.

## Features (Class XI IP)

- 10-chapter study guide aligned to the KIPS textbook (CBSE Code 065)
- MCQ practice with XP points and difficulty levels
- Python coding challenges with an in-browser sandboxed runner
- AI Tutor powered by Google Gemini (free, no credit card needed)
- Progress tracking with streaks, badges, and daily XP goals
- Works fully offline — AI features are optional

## Requirements

- Python 3.8 or later
- Internet connection only needed for the AI Tutor feature
